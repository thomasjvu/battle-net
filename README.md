# Battle Net

![Relay Town title-screen artwork](dist/assets/title/relay-town.webp)

Battle Net is a real-time card tactics RPG built for the NEAR Hackathon. Explore the network from Relay Town, build a 30-chip folder, and fight grid battles. The Trading Hall lets players trade, transfer, and forge items on NEAR testnet.

## Play locally

Requires Node.js 22.22.2+ and Python 3.

```sh
npm ci
npm run build
npm run dev
```

Open [localhost:4173](http://localhost:4173) and choose **Jack In**.
